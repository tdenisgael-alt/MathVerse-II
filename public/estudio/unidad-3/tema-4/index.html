Tema 04 · Análisis Vectorial

El rotacional es un operador diferencial vectorial que cuantifica la tendencia microscópica de un campo a girar o circular en torno a un punto dado. Mientras que la divergencia evalúa la expansión o compresión volumétrica, el rotacional mide la vorticidad espacial y la orientación del eje instantáneo de rotación. Constituye la herramienta matemática fundamental para determinar si un campo de fuerzas es conservativo y para formular las ecuaciones del electromagnetismo de Maxwell.

Rotacional de un campo vectorial

Material complementario estructurado según los estándares de Cálculo Multivariable y Análisis Vectorial universitario (referencias: James Stewart, Marsden & Tromba, Thomas).

Definición analítica formal

Sea F = P i + Q j + R k un campo vectorial cuyas funciones componentes poseen derivadas parciales de primer orden continuas en un subconjunto abierto de ℝ³:

Definición: Rotacional de un campo vectorial

El rotacional de F (denotado por rot F o ∇ × F) es el campo vectorial resultante del producto cruz formal del operador Nabla con el campo:
rot F = ∇ × F = | i   j   k ;   ∂∂x   ∂∂y   ∂∂z ;   P   Q   R |

Desarrollando los cofactores 2×2 de derivadas cruzadas:
∇ × F = ( ∂R∂y − ∂Q∂z ) i + ( ∂P∂z − ∂R∂x ) j + ( ∂Q∂x − ∂P∂y ) k

• Caso bidimensional en ℝ²:
Para un campo plano F(x, y) = ⟨ P(x, y), Q(x, y), 0 ⟩, las componentes en i y j se anulan, sobreviviendo únicamente la componente perpendicular al plano:
rotz F = ( ∇ × F ) · k = ∂Q∂x − ∂P∂y.

Interpretación física y geométrica: vorticidad y rueda de paletas

Para comprender físicamente el vector rotacional, imaginemos un fluido incompresible con velocidad descrita por F y coloquemos en un punto P₀ una diminuta rueda de paletas (paddle wheel) libre de girar sobre un eje de orientación espacial n.

1. Eje de máxima velocidad de rotación:
La rueda de paletas girará a la máxima velocidad angular posible cuando su eje esté alineado con la dirección del vector ∇ × F(P₀). La regla de la mano derecha determina el sentido del giro.

2. Magnitud del rotacional y velocidad angular:
La velocidad angular de giro ω del molinete satisface rigurosamente:
‖∇ × F(P₀)‖ = 2 ω.
La magnitud del rotacional duplica la velocidad angular instantánea del medio continuo en ese punto.

3. Definición geométrica intrínseca mediante circulación límite:
( ∇ × F(P₀) ) · n = limΔA → 0 1ΔA ∮∂A F · dr,
donde ∮∂A F · dr es la circulación del campo a lo largo de la curva cerrada frontera ∂A orientada positivamente respecto a la normal n.

Campos irrotacionales y criterio de campos conservativos

Un campo vectorial F se denomina irrotacional en un dominio D si su rotacional es idénticamente nulo en todo punto:
∇ × F ≡ 0    ∀ (x, y, z) ∈ D.

Teorema fundamental de campos conservativos e irrotacionales

Sea F un campo vectorial de clase C¹ definido sobre un dominio D ⊂ ℝ³ que sea simplemente conexo (es decir, conexo y sin «agujeros» o lazos que no puedan encogerse continuamente a un punto):

El campo vectorial F es conservativo si y solo si es irrotacional en D:
F = ∇f    ⇔    ∇ × F = 0.

• Advertencia topológica crucial: La hipótesis de que D sea simplemente conexo es obligatoria. Si el dominio posee un vacío interior (como el plano perforado ℝ² \ {(0,0)}), un campo puede tener rotacional nulo en todo punto del dominio sin ser conservativo.

Ejemplos resueltos paso a paso

Ejemplo 1: Rotacional del campo de rotación rígida y velocidad angular
Un cuerpo rígido gira con velocidad angular constante ω = ω k en torno al eje Z. El campo de velocidades lineales es v = ω × r = ⟨ −ω y,   ω x,   0 ⟩.
• Solución paso a paso:
1) Componentes del campo: P = −ω y, Q = ω x, R = 0.
2) Evaluamos cada componente del rotacional:
- Componente i: ∂R∂y − ∂Q∂z = 0 − 0 = 0.
- Componente j: ∂P∂z − ∂R∂x = 0 − 0 = 0.
- Componente k: ∂Q∂x − ∂P∂y = ∂(ω x)∂x − ∂(−ω y)∂y = ω − (−ω) = 2ω.
3) Vector rotacional resultante:
∇ × v = ⟨ 0, 0, 2ω ⟩ = 2 ω.
Se confirma exactamente que el rotacional es el doble de la velocidad angular y apunta a lo largo del eje de rotación.

Ejemplo 2: Demostración de campo conservativo y cálculo del potencial
Dado el campo vectorial F(x, y, z) = ⟨ 2x y + z²,   x² + 2y z,   2x z + y² ⟩:
a) Demostrar que F es un campo conservativo en todo ℝ³.
b) Determinar una función potencial escalar f(x, y, z) tal que ∇f = F.
• Solución paso a paso:
1) Cálculo del rotacional:
rotx = ∂(2xz + y²)∂y − ∂(x² + 2yz)∂z = 2y − 2y = 0.
roty = ∂(2xy + z²)∂z − ∂(2xz + y²)∂x = 2z − 2z = 0.
rotz = ∂(x² + 2yz)∂x − ∂(2xy + z²)∂y = 2x − 2x = 0.
Por ser ∇ × F = 0 en todo ℝ³ (que es simplemente conexo), F es estrictamente conservativo.
2) Construcción del potencial por integraciones sucesivas:
- Integramos ∂f∂x = 2x y + z² ⇒ f(x, y, z) = x² y + x z² + g(y, z).
- Derivamos respecto a y:
∂f∂y = x² + ∂g∂y. Igualando con Q = x² + 2y z:
∂g∂y = 2y z ⇒ g(y, z) = y² z + h(z).
- Derivamos la expresión acumulada f = x² y + x z² + y² z + h(z) respecto a z:
∂f∂z = 2x z + y² + h'(z). Igualando con R = 2x z + y²:
h'(z) = 0 ⇒ h(z) = C.
Por consiguiente, la familia de funciones potenciales es:
f(x, y, z) = x² y + x z² + y² z + C.

Ejercicios de práctica resueltos

Ejercicio 1: Campo irrotacional tridimensional simétrico
Determinar si F(x, y, z) = ⟨ y z,   x z,   x y ⟩ es irrotacional y hallar su potencial.
• Solución explicada:
1) Componentes del rotacional:
∇ × F = ⟨ ∂(xy)∂y − ∂(xz)∂z,   ∂(yz)∂z − ∂(xy)∂x,   ∂(xz)∂x − ∂(yz)∂y ⟩ = ⟨ x − x,   y − y,   z − z ⟩ = ⟨ 0, 0, 0 ⟩.
2) El campo es irrotacional en todo ℝ³.
3) Su función potencial inmediata es f(x, y, z) = x y z + C, ya que sus derivadas parciales reproducen con exactitud ⟨ y z, x z, x y ⟩.

Ejercicio 2: El contraejemplo clásico del vórtice en dominio perforado
Sea el campo en el plano perforado D = ℝ² \ {(0,0)}:
F(x, y) = ⟨ −yx² + y²,   xx² + y² ⟩.
Demostrar que rotz F = 0 en todo punto de D, pero el campo NO es conservativo.
• Solución explicada:
1) Calculamos las derivadas parciales cruzadas:
∂Q∂x = (1)(x² + y²) − x(2x)(x² + y²)² = y² − x²(x² + y²)².
∂P∂y = (−1)(x² + y²) − (−y)(2y)(x² + y²)² = y² − x²(x² + y²)².
Restando: rotz F = ∂Q∂x − ∂P∂y = 0 en todo punto regular (x, y) ≠ (0, 0).
2) Circulación sobre la circunferencia unitaria C: r(t) = ⟨ cos t, sen t ⟩, t ∈ [0, 2π]:
∮C F · dr = ∫₀2π [ (−sen t)(−sen t) + (cos t)(cos t) ] dt = ∫₀2π 1 dt = 2π ≠ 0.
Como la circulación sobre una curva cerrada no es cero, el campo no es conservativo en D. Esto ocurre porque el dominio ℝ² \ {(0,0)} no es simplemente conexo (posee un agujero en el origen).
