Tema 03 · Análisis Vectorial

La divergencia cuantifica el comportamiento de emanación o absorción neta de un campo vectorial en cada punto del espacio. Físicamente, mide la tasa neta de flujo que atraviesa la frontera de un volumen infinitesimal por unidad de volumen. Su valor escalar permite clasificar los puntos del medio como fuentes (producción o expansión local de fluido), sumideros (absorción o compresión local) o zonas incompresibles con carácter solenoidal.

Divergencia de un campo vectorial

Material complementario estructurado según los estándares de Cálculo Multivariable y Análisis Vectorial universitario (referencias: James Stewart, Marsden & Tromba, Thomas).

Definición analítica formal

Sea F un campo vectorial diferenciable en un dominio abierto de ℝ³ o ℝ²:

Definición: Divergencia de un campo vectorial

1. En ℝ³, para F(x, y, z) = P i + Q j + R k, la divergencia es el campo escalar:
div F = ∇ · F = ∂P∂x + ∂Q∂y + ∂R∂z

2. En el plano ℝ², para F(x, y) = ⟨ P(x, y), Q(x, y) ⟩:
div F = ∇ · F = ∂P∂x + ∂Q∂y

• Propiedad de linealidad:
∇ · (a F + b G) = a (∇ · F) + b (∇ · G) para cualesquiera constantes reales a, b.

Interpretación geométrica y física: densidad de flujo

Consideremos un volumen elemental con forma de caja paralelepipédica centrada en P₀(x, y, z) con aristas Δx, Δy, Δz. El flujo neto que sale a través de las dos caras perpendiculares al eje X es aproximadamente:
Flujox ≈ [ P(x + Δx2, y, z) − P(x − Δx2, y, z) ] Δy Δz ≈ ∂P∂x Δx Δy Δz.
Sumando los flujos netos a través de las seis caras y dividiendo entre el volumen elemental ΔV = Δx Δy Δz, en el límite cuando ΔV → 0 se obtiene la definición intrínseca de la divergencia independiente de coordenadas:

div F(P₀) = limΔV → 0 1ΔV ∬∂V F · n dS

Donde ∂V es la superficie frontera cerrada que encierra a ΔV y n es el vector normal unitario exterior.

Diagnóstico del comportamiento físico: fuentes, sumideros y campos solenoidales

La evaluación del signo de la divergencia en un punto o en una región permite clasificar el comportamiento del campo:

1. Fuente (Source, ∇ · F > 0):
El flujo neto que sale de cualquier vecindad del punto supera al flujo que entra. Existe una emanación o generación neta de fluido (o densidad) en ese punto; el medio se expande localmente.

2. Sumidero (Sink, ∇ · F < 0):
El flujo entrante supera al flujo saliente. Existe absorción o compresión neta de masa/energía en el punto.

3. Campo solenoidal o incompresible (∇ · F ≡ 0):
Si la divergencia es idénticamente nula en todo un dominio abierto D, el campo se denomina solenoidal. En un campo solenoidal no hay fuentes ni sumideros; la cantidad de fluido que entra a cualquier volumen cerrado es exactamente igual a la que sale.

Distinción esencial: Propiedad local en P₀ vs. Carácter global del campo

• Propiedad local en un punto P₀: Que ∇ · F(P₀) = 0 en un punto aislado únicamente indica que en ese punto específico no hay generación ni absorción neta de flujo.
• Carácter solenoidal global: Para que el campo sea calificado rigurosamente como solenoidal o incompresible, su divergencia debe ser idénticamente nula en todos los puntos del dominio (∇ · F ≡ 0 ∀ (x, y, z) ∈ D).
Ejemplo: Para F = ⟨ x², 0, 0 ⟩, se tiene ∇ · F = 2x. En el plano x = 0 la divergencia es cero, pero el campo NO es solenoidal globalmente.

Ejemplos resueltos paso a paso

Ejemplo 1: Análisis de expansión no homogénea y puntos críticos
Sea el campo vectorial F(x, y, z) = ⟨ x³, y³, z³ ⟩.
• Solución paso a paso:
1) Calculamos las derivadas parciales de cada componente:
∂P∂x = ∂(x³)∂x = 3x²,  ∂Q∂y = ∂(y³)∂y = 3y²,  ∂R∂z = ∂(z³)∂z = 3z².
2) Expresión general de la divergencia:
∇ · F(x, y, z) = 3x² + 3y² + 3z² = 3(x² + y² + z²).
3) Diagnóstico físico en el dominio:
- En el origen O(0, 0, 0): ∇ · F(0, 0, 0) = 0 (divergencia nula puntual).
- Para todo punto (x, y, z) ≠ (0, 0, 0): como x² + y² + z² > 0, se tiene ∇ · F > 0.
El campo actúa como una fuente expansiva en todo el espacio tridimensional excepto en el origen puntual.

Ejemplo 2: Carácter solenoidal de un vórtice circular plano
Determinar la divergencia del campo de rotación pura F(x, y) = ⟨ −y, x ⟩.
• Solución paso a paso:
1) Componentes: P(x, y) = −y, Q(x, y) = x.
2) Derivadas parciales directas:
∂P∂x = ∂(−y)∂x = 0,   ∂Q∂y = ∂(x)∂y = 0.
3) Divergencia total: ∇ · F = 0 + 0 = 0 para todo (x, y) ∈ ℝ².
El campo es globalmente solenoidal. El fluido gira sin comprimirse ni expandirse en ningún punto.

Ejercicios de práctica resueltos

Ejercicio 1: Parámetros para solenoididad condicional
Dado el campo F(x, y, z) = ⟨ a x + 2y,   3x − a y,   z² ⟩, calcular su divergencia y determinar en qué superficie el campo es incompresible.
• Solución explicada:
1) Derivadas parciales:
∂P∂x = a,  ∂Q∂y = −a,  ∂R∂z = 2z.
2) Suma: ∇ · F = a + (−a) + 2z = 2z.
3) Análisis: Los términos con el parámetro a se cancelan mutuamente para cualquier valor real de a. El campo es incompresible (∇ · F = 0) exactamente sobre el plano horizontal z = 0 (el plano XY). En el semiespacio superior z > 0 actúa como fuente (∇ · F > 0) y en el inferior z < 0 como sumidero (∇ · F < 0).

Ejercicio 2: Divergencia de campos centrales generales rn r
Sea r = ⟨ x, y, z ⟩ y r = ‖r‖ = √x² + y² + z². Calcular la divergencia del campo central F = rn r para r > 0.
• Solución explicada:
1) Aplicando la regla del producto escalar: ∇ · (rn r) = rn (∇ · r) + (∇rn) · r.
2) Calculamos ∇ · r = ∂x∂x + ∂y∂y + ∂z∂z = 1 + 1 + 1 = 3.
3) Calculamos ∇rn = n rn−1 ∇r = n rn−1 ( rr ) = n rn−2 r.
4) Multiplicando escalarmente por r:
(∇rn) · r = (n rn−2 r) · r = n rn−2 (r · r) = n rn−2 (r²) = n rn.
5) Sumando ambos términos:
∇ · (rn r) = 3 rn + n rn = (n + 3) rn.
Caso físico trascendental: Para el campo de la ley de Coulomb o de gravitación newtoniana, n = −3 (F = rr³). La divergencia resulta:
∇ · ( rr³ ) = (−3 + 3) r−3 = 0   (∀ r > 0).
En todo punto fuera del origen puntual, el campo newtoniano es estrictamente solenoidal.
