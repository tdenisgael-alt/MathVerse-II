Tema 02 · Análisis Vectorial

En el cálculo multivariable avanzado, los operadores diferenciales sintetizan las tasas de variación espacial en una notación algebraica unificada de extraordinaria potencia. El operador formal Nabla (∇) actúa como el núcleo unificador entre campos escalares y vectoriales, generando el gradiente, la divergencia y el rotacional. Asimismo, su composición produce el operador Laplaciano (∇²), eje central de la teoría de funciones armónicas, la transmisión de calor, la electrostática y la mecánica cuántica.

Operadores diferenciales y campos escalares y vectoriales

Material complementario estructurado según los estándares de Cálculo Multivariable y Análisis Vectorial universitario (referencias: James Stewart, Marsden & Tromba, Thomas).

El operador formal Nabla (∇)

En el espacio euclidiano tridimensional ℝ³ con base ortonormal estándar {i, j, k}, se define el operador diferencial vectorial Nabla (denotado por el símbolo ∇ o del) como un vector simbólico cuyos componentes son los operadores de derivación parcial:

Definición: Operador diferencial Nabla

∇ = i ∂∂x + j ∂∂y + k ∂∂z = ⟨ ∂∂x,   ∂∂y,   ∂∂z ⟩

Nabla no es un vector de cantidades numéricas, sino un operador diferencial. Al aplicarse sobre entidades matemáticas de distintos rangos tensoriales, produce tres operaciones fundamentales:

1. Gradiente de un campo escalar: ∇f = ⟨ ∂f∂x, ∂f∂y, ∂f∂z ⟩ (transforma un campo escalar en un campo vectorial).
2. Divergencia de un campo vectorial: ∇ · F = ∂P∂x + ∂Q∂y + ∂R∂z (producto escalar formal; transforma un campo vectorial en un campo escalar).
3. Rotacional de un campo vectorial: ∇ × F (producto vectorial formal; transforma un campo vectorial en otro campo vectorial).

El operador Laplaciano (Δ = ∇²) y funciones armónicas

Al aplicar el operador divergencia sobre el campo gradiente de una función escalar f dos veces diferenciable (f ∈ C²), se obtiene el operador Laplaciano (denotado por ∇² o Δ):

∇² f = ∇ · (∇f) = ∂∂x( ∂f∂x ) + ∂∂y( ∂f∂y ) + ∂∂z( ∂f∂z ) = ∂²f∂x² + ∂²f∂y² + ∂²f∂z².

• Ecuación de Laplace y funciones armónicas:
Una función escalar f que satisface la ecuación diferencial en derivadas parciales:
∇² f = 0
se denomina función armónica. Las funciones armónicas gozan de la propiedad del valor medio y del principio del máximo, describiendo distribuciones estacionarias de temperatura, potenciales electrostáticos en regiones libres de carga y flujos potenciales incompresibles.

Identidades vectoriales de segundo orden fundamentales

Entre las identidades diferenciales más relevantes destacan:

Teorema: Identidades diferenciales de segundo orden

Para todo campo escalar f y campo vectorial F con derivadas parciales continuas de segundo orden en su dominio:

1. El rotacional de un campo gradiente es idénticamente nulo:
∇ × (∇f) = 0.
Consecuencia física: Todo campo de fuerzas conservativo carece de rotación microscópica (es irrotacional).

2. La divergencia del rotacional de cualquier campo vectorial es nula:
∇ · (∇ × F) = 0.
Consecuencia física: En electromagnetismo, como el campo magnético deriva de un potencial vector (B = ∇ × A), se deduce la ley de Gauss magnética: ∇ · B = 0 (inexistencia de monopolos magnéticos aislados).

3. Reglas del producto diferencial:
- ∇ · (f F) = f (∇ · F) + (∇f) · F.
- ∇ × (f F) = f (∇ × F) + (∇f) × F.

Demostración analítica rigurosa: ∇ × (∇f) = 0

Sea f(x, y, z) de clase C². El gradiente es ∇f = ⟨ fx, fy, fz ⟩.
Calculamos su rotacional mediante el determinante mnemotécnico formal:
∇ × (∇f) = | i   j   k ;   ∂∂x   ∂∂y   ∂∂z ;   ∂f∂x   ∂f∂y   ∂f∂z |.
Desarrollando por cofactores en la primera fila:
- Componente i: ∂∂y( ∂f∂z ) − ∂∂z( ∂f∂y ) = ∂²f∂y∂z − ∂²f∂z∂y.
- Componente j: −[ ∂∂x( ∂f∂z ) − ∂∂z( ∂f∂x ) ] = ∂²f∂z∂x − ∂²f∂x∂z.
- Componente k: ∂∂x( ∂f∂y ) − ∂∂y( ∂f∂x ) = ∂²f∂x∂y − ∂²f∂y∂x.
Por el Teorema de Schwarz/Clairaut de igualdad de derivadas parciales mixtas para funciones C², cada uno de estos paréntesis es exactamente cero:
∇ × (∇f) = 0 i + 0 j + 0 k = 0.
Queda formalmente demostrado.

Ejemplos resueltos paso a paso

Ejemplo 1: Verificación de función armónica para el potencial newtoniano
Demostrar que el potencial radial f(x, y, z) = 1r = 1√x² + y² + z² es armónico para todo punto fuera del origen (r > 0).
• Solución paso a paso:
1) Derivadas de primer orden respecto a x:
∂f∂x = −1r² ∂r∂x = −xr³ (recordando que ∂r∂x = xr).
2) Derivadas de segundo orden respecto a x por la regla del cociente:
∂²f∂x² = −(1)(r³) − x (3r² xr)r⁶ = −r³ − 3x² rr⁶ = −r² − 3x²r⁵ = 3x² − r²r⁵.
3) Por simetría radial en y y z:
∂²f∂y² = 3y² − r²r⁵,    ∂²f∂z² = 3z² − r²r⁵.
4) Sumando los tres términos para obtener el Laplaciano:
∇² f = (3x² − r²) + (3y² − r²) + (3z² − r²)r⁵ = 3(x² + y² + z²) − 3r²r⁵ = 3r² − 3r²r⁵ = 0.
Por consiguiente, ∇² ( 1r ) = 0 para todo r > 0.

Ejemplo 2: Comprobación de ∇ · (∇ × F) = 0 sobre un campo vectorial
Sea F(x, y, z) = ⟨ x² y,   y² z,   z² x ⟩. Calcular explícitamente ∇ × F y luego su divergencia.
• Solución paso a paso:
1) Cálculo de componentes del rotacional:
- Componente x: ∂(z²x)∂y − ∂(y²z)∂z = 0 − y² = −y².
- Componente y: ∂(x²y)∂z − ∂(z²x)∂x = 0 − z² = −z².
- Componente z: ∂(y²z)∂x − ∂(x²y)∂y = 0 − x² = −x².
Por tanto: ∇ × F = ⟨ −y², −z², −x² ⟩.
2) Cálculo de la divergencia del resultado:
∇ · (∇ × F) = ∂(−y²)∂x + ∂(−z²)∂y + ∂(−x²)∂z = 0 + 0 + 0 = 0.
La identidad se verifica de manera idéntica.

Ejercicios de práctica resueltos

Ejercicio 1: Función armónica bidimensional
Demostrar que la función u(x, y) = ex cos y es armónica en todo el plano ℝ².
• Solución explicada:
1) Derivadas parciales en x: ux = ex cos y ⇒ uxx = ex cos y.
2) Derivadas parciales en y: uy = −ex sen y ⇒ uyy = −ex cos y.
3) Laplaciano: ∇² u = uxx + uyy = ex cos y + (−ex cos y) = 0.
La función cumple la ecuación de Laplace en todo ℝ².

Ejercicio 2: Regla del producto para la divergencia
Calcular ∇ · (f F) para f(x, y, z) = x y y F(x, y, z) = ⟨ y, z, x ⟩.
• Solución explicada:
1) Campo producto: f F = ⟨ x y², x y z, x² y ⟩.
2) Divergencia directa:
∇ · (f F) = ∂(x y²)∂x + ∂(x y z)∂y + ∂(x² y)∂z = y² + x z + 0 = y² + x z.
3) Verificación mediante la regla de la identidad: ∇·F = 0 + 0 + 0 = 0, ∇f = ⟨ y, x, 0 ⟩.
(∇f) · F = ⟨ y, x, 0 ⟩ · ⟨ y, z, x ⟩ = y² + x z + 0 = y² + x z.
Ambos métodos arrojan el mismo resultado exacto.
